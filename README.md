# Jadual — Sistem Jadual Waktu Sekolah

Sistem web untuk menjana jadual waktu sekolah secara automatik.
Satu fail HTML, tiada pemasangan, tiada pelayan. Data disimpan dalam pelayar pengguna.

## Pautan

| Untuk | Pautan | Keterangan |
|---|---|---|
| Penyelaras jadual | https://sepadan.github.io/Jadual/ | Aplikasi penuh — masukkan data, jana, edit, cetak |
| Semua guru | https://sepadan.github.io/Jadual/jadual.html | Paparan baca sahaja — pilih nama, lihat & cetak jadual sendiri |

## Ciri

- Jana jadual automatik tanpa pertembungan guru & kelas
- Peruntukan waktu mengikut tahun (Tahun 1–6)
- Kekangan: maks waktu sehari, maks waktu berturut, subjek teras waktu pagi, had kemudahan (cth. PADANG)
- Slot tetap: perhimpunan, kokurikulum, bacaan Al-Quran
- Kunci blok tertentu supaya kekal semasa jana semula
- Edit manual dengan semakan pertembungan automatik
- Jadual guru, jadual kelas, jadual induk
- Cetak / simpan PDF A4 landskap
- Eksport fail paparan guru, JSON dan CSV

## Kemas kini jadual

1. Buka aplikasi, jana atau edit jadual
2. Menu **Cetak / PDF** → **Eksport Fail Paparan Guru**
3. Namakan fail sebagai `jadual.html`
4. Muat naik ke repositori ini (ganti fail lama)

Pautan guru kekal sama.

## Sandaran data

Data hanya wujud dalam pelayar peranti anda. Guna **Data & Sandaran → Eksport JSON**
secara berkala, dan simpan fail itu di tempat selamat.
